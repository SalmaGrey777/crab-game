
Crab Adventure Game
Description:
This is a simple Scratch game where you control a crab using the arrow keys to collect starfish while avoiding a shark. Each collected starfish increases the score, but be careful! If the shark catches the crab, you lose points.

Controls:
Arrow keys → Move the crab
Collect starfish → Gain points
Avoid the shark → Stay safe!
How to Play:
Click the green flag to start the game. Guide the crab using the arrow keys and try to collect as many starfish as possible while escaping from the shark.
